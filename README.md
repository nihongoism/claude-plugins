# Nihongoism plugins for Claude Code

Plugins from [Nihongoism](https://nihongoism.com), the newsletter that explores Japanese one word at a time. This repository is the `nihongoism` plugin marketplace; each plugin lives in its own folder under `plugins/`.

## Install

```
/plugin marketplace add nihongoism/claude-plugins
/plugin install brush-kanji@nihongoism
```

## Plugins

| Plugin | What it does |
|---|---|
| [brush-kanji](plugins/brush-kanji/) | Draws a kanji the way a brush writes it: an animated page that brushes the character stroke by stroke onto paper, built on [KanjiVG](https://kanjivg.tagaini.net/) stroke data |
